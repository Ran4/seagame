# Singing and dancing skill effects not implemented

Singing (0-255) is tracked and gains +0.3/s while singing shanties. No mastery effect yet.

Dancing (0-255) is tracked but has no activity trigger (no dancing state exists). No mastery effect yet.

Possible future effects at 192+:
- Singing mastery: bigger morale boost from shanties, attracts more singers
- Dancing mastery: TBD when dancing mechanic is added
