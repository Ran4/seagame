# Singing and dancing skill mastery effects not implemented

Singing (0-255) is tracked and gains +0.3/s while singing shanties. No mastery effect yet.

Dancing (0-255) is tracked and gains +0.3/s while dancing. No mastery effect yet.

Possible future effects at 192+:
- Singing mastery: bigger morale boost from shanties, attracts more singers
- Dancing mastery: bigger morale/friendship boost, longer dances, attracts more dancers
